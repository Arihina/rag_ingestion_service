# Тесты

```bash
python -m unittest discover -s tests -t .          # всё
python -m unittest tests.test_archive              # один модуль
python -m unittest tests.test_archive.ArchiveRejectionTests -v
```

Внешних сервисов не требуется: Postgres, Redis, SeaweedFS, OpenSearch и
docling подменяются. Модель эмбеддингов не загружается — `FlagEmbedding`
импортируется лениво внутри `BgeM3Embedder`, и до него тесты не доходят.

## Что где

| Модуль | Предмет |

| `test_chunk_identity.py` | формула `_id`, коллизии между наборами, идемпотентность |
| `test_index_mapping.py` | маппинг `kb-v2`: анализаторы, размерность, метрика, rank_features |
| `test_search_isolation.py` | фильтр `rag_id` в запросах загрузчика, `refresh` при bulk |
| `test_scoring.py` | преобразование косинус ↔ `_score` и его обратимость |
| `test_archive.py` | zip: бомба, traversal, коллизии имён, лимиты, пропуски |
| `test_docling_client.py` | разбор чанков, форма запроса v1, опрос задачи |
| `test_options.py` | имена полей опций: JSON против multipart |
| `test_status.py` | производный статус набора |
| `test_schemas.py` | границы конфига набора |
| `test_repo_queries.py` | владение внутри SQL, инварианты схемы |

| `test_api_rags.py` | коды ответов, скоупинг, валидация, иконки |

## Принципы

**Проверяется то, что ломается молча.** Приоритет у мест, где ошибка не
даёт исключения: забытый фильтр `rag_id`, неверное имя поля опций docling
(pydantic на той стороне молча выбрасывает неизвестные поля), коллизия
`_id` между наборами, `_score` принятый за косинус.

**Транспорт мокается, а не методы.** `httpx.MockTransport` вместо патча
`post` — так проверяется настоящее тело запроса в том виде, в каком его
сериализует httpx, включая multipart-границы.

**Структура SQL вместо результата.** Живого Postgres нет, поэтому запросы
компилируются под диалект и проверяются на наличие условий владения. Это
ловит именно тот класс ошибок, который дорого стоит.

**Фикстуры коммитятся.** См. `data/README.md`: сгенерированные заново
zip-архивы могут получить другие коэффициенты сжатия и тихо перестать
проверять то, ради чего заведены.
