# Фикстуры тестов

Данные коммитятся, а не генерируются на лету: zip-фикстуры несут конкретные
коэффициенты сжатия и структуру имён, и пересозданные на другой версии zlib
могут тихо перестать проверять то, ради чего заводились.

## archives/

| Файл | Что проверяет |
|---|---|
| `plain.zip` | нормальный путь: три файла, один во вложенном каталоге |
| `traversal.zip` | `../../etc/passwd.txt` и windows-вариант со слэшами наоборот |
| `collision.zip` | `a/doc.txt`, `b/doc.txt`, `c/doc.txt` — после сплющивания имена совпадают |
| `bomb.zip` | 20 МБ нулей: коэффициент сжатия в сотни раз |
| `too_many.zip` | 2100 записей при лимите 2000 |
| `mixed.zip` | вложенный архив, `.exe`, файл без расширения, валидный `.png` и `.txt` |
| `encrypted.zip` | архив под паролем |
| `empty.zip` | ноль записей |

## docling/

Ответы docling-serve v1.21: приём задачи, три состояния опроса и результат
чанкинга. В `chunk_result.json` намеренно смешаны формы: чанк с
`raw_text` + `contextualized_text`, чанк со страницами в `meta.doc_items[].prov`,
чанк только с `contextualized_text`, и два пустых — они должны отбрасываться.

`status_failure.json` содержит реальное сообщение про отклонённый allowlist'ом
URL: без разбора `task_meta` из него не видно причины.

## icons/

`icon.png` и `large.png` — валидные PNG (8x8 и 512x512).
`evil.svg` — SVG со скриптом, приниматься не должен.
`not_an_image.png` — правильная сигнатура PNG и мусор дальше: проверяет, что
валидация идёт разбором, а не по первым байтам.
